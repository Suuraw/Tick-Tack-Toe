## Tic-Tac-Toe Game


# Overview
This repository contains a simple Tic-Tac-Toe game built using React. The project serves as a practical implementation of React concepts, allowing users to play the classic game in their web browser.

# Key Features
Interactive Gameplay: Players can take turns marking Xs and Os on a 3x3 grid.
Game Logic: The game checks for winners and handles draws.
Responsive Design: The game is designed to be user-friendly and responsive across different devices.

# Learning Experience
While developing this project, I gained valuable insights into:
Functional Logic: Understanding how to write clean and efficient functional logic in React.
React Hooks: Learning how to effectively use useState for managing component state and useEffect for handling side effects in functional components.
